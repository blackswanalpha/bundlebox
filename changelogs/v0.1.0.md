# v0.1.0 — 2026-09-13

First public release. A dependency-free Node port of the bundlebox software
factory, generalised from one workspace to any repository and any AI coding
agent.

## Added
- Sixteen generic zero-token detectors with stable ids, evidence and expected-value triage.
- Local actuators that write a patch before they write a file and decline with a reason.
- Compile: anchored regions, hoisted evidence, cache-stable brief prefix, four-term budget model with FITS/TIGHT/SPLIT/HEAVY verdicts and locality-aware splits.
- Route: lanes with conflicts as affinity, wave scheduling, worktree planning, stable session ids.
- Run: adapters for Claude Code, Codex, Gemini CLI, OpenCode, Aider, Cursor, Copilot and custom commands; dry-run by default; env allowlist; hard timeouts; acceptance as the verdict; `unproven` as a state.
- Tokens: three-count estimator with transcript calibration, session accounting with MEASURED / ESTIMATE rows, price table with provenance, lean-stack probe.
- Snapgen tables, pinpoint briefs, oversight metrics and guidelines, pipelines with fingerprinted skips, episodes and process learning, bridge calls with a fail-closed ceiling.
- `bb wire` installs hooks, instruction blocks and MCP entries into ten agents; `bb mcp` serves the verbs over stdio with no dependency.
- A Rust kernel (`bbk`) for walk, fingerprint, estimate, dupes, symbols, anchor, gate and worktree, with JS fallbacks and parity tests; `bb kernel install|build`.
- A stdlib Python expert system for the rule engine, triage, confidence, signals, rules, graph, model and memory, with JS parity tests.
- Installer script, `bb update`, GitHub release flow with npm provenance and kernel binaries for five targets.
