# v0.9.0 — 2026-09-27

The release where `bb scan` takes half the time on a large tree, and
`bb sentinel` runs everything free before it spends on an agent.

## Added

- **`bb sentinel`** (#82, #84). Runs every check that needs no model first,
  then hands only what is left to agent lanes inside the daily budgets. #84
  adds the Python policy, kernel ops, and links into lathe and arc.
- **`bb pipeline tail`** and a console gears panel (#79). `tail` streams gear
  runs and stages from `gear_runs.jsonl` and `episodes.jsonl` until Ctrl-C
  (`--gear`, `--verbose`, `--json`). The console shows runs per gear over 24h,
  7d and all time, with failures, average seconds and the latest 15 runs.
- Bench page changes and new tests for doctor, drivers, facts, packs, ratify,
  swebench and six expert modules (#81).
- One-page pitch, deck and PDF under `docs/pitch/` (#70).

## Changed

- **Scan and pinpoint performance** (#71 to #76). On a shallow clone of django
  (7,091 files) `bb scan` went from 22 s to about 11 s. Each file is hashed and
  counted once, five detectors stop rescanning the corpus per candidate, the
  kernel's `dupes` keys windows by interned line ids, `resolve()` memoises by
  spec, and a per-file cache keyed by content sha1 carries single-file
  derivations between scans. `importGraph` and `dead-deps` read import specs
  through that cache (#77, #78).
- **Findings noise** (#80). Open findings on this tree went from 826 to 192. A
  window where half or more rows are a bare string literal is no longer a
  duplicate block, in JS and in the kernel. `oversight:god-file` and
  `oversight:duplication` no longer reach the findings board. `bb findings`
  defaults to 20 rows, most-committed files first within a severity.
- The cut-file prompt suggests a pasteable `bb pinpoint` command (#83, #86).

## Fixed

- `orient` skips `arc build` when the arc binary is absent. An npm install
  ships no binary, and this was 104 of `orient`'s 119 recorded failures (#79).
- `bb` waits for stdout and stderr to flush on exit. `bb findings --json | …`
  stopped at 65,536 bytes (#81).

## Known issues

- `test/doctor.test.js` fails on Windows: the `repository` row reports `warn`
  for a workspace whose git lives in a subdirectory. The release gate runs on
  Ubuntu.
- A kernel installed before this release reports help tables as duplicate
  blocks. `bb kernel install` fetches the new one.
