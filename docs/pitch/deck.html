bundlebox

Cuts what AI coding agents are billed for by answering their orientation questions locally, before the agent opens.

Victor Mbugua · Pitch · September 2026MIT · npm i -g bundlebox
01 · Problem

Agents are billed for reading, and most of what they read is orientation.

Before an agent changes a line, it reads files to learn where a symbol lives, which files a task touches, whether two tables agree and what changed since last week. A parser, a count or a set difference answers each of those for free. Teams pay model prices for them anyway, on every session and by every developer.

02 · How it works

Answer what code can answer, then open the agent.

TaskA developer hands work to Claude Code, Codex, Gemini CLI or OpenCode.
bundleboxParses, counts and diffs the repo locally. Zero model tokens.
BriefFiles, symbols and answers, packed to fit the agent's window.
LedgerMeasures what the session used and what it was spared.

05 · Business model

The CLI stays free. Teams pay per seat for the hosted layer.

Free, MIT

  • The CLI, the local answers and the brief.
  • Every agent adapter.
  • Per-session savings for one developer.

Paid, per seat

  • A shared ledger of what each session used and saved.
  • An org dashboard of spend per repo, developer and vendor.
  • Budget and policy controls across every agent.

The price stays below the tokens it measurably saves.
